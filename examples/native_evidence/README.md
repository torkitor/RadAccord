This report comes from the first synthetic PyRadiomics identity pair in the
frozen 1.2.0rc2 native reevaluation. It is not a hand-written example or a clinical
image. The complete source record is retained in
`results/native_refinement/pyradiomics/cases.jsonl` and in the immutable refinement
archive. The installed distribution may be newer; the report keeps the version
and hashes of the execution that actually produced it.

Open `report.html` locally, inspect `report.json`, or read `methods.txt`. The HTML
makes no external requests. Use a methods paragraph generated from **your own**
execution for research reporting; these example checks do not describe your data.
